# java-racingcar-precourse

## 기능
- [ ] 구분자로 이뤄진 자동차 이름들과 라운드 수를 설정한다.
  - 아래 항목이 지켜지지 않은 경우 `예외 상황`에 정의된 내용을 따른다.
    - [ ] 구분자는 `,`여야 한다.
    - [ ] 자동차의 이름은 내부 공백을 제외한 공백으로만 채워진 문자열 값, 양 옆의 공백을 제외한 최대 5글자로 채워져야 한다.   
- [ ] 라운드 진행
  - [ ] 라운드 별 전진 조건은 `0 ~ 9`의 랜덤 숫자를 얻어 4 이상인 경우 한 칸 전진시킨다.
  - [ ] 각 라운드마다 자동차들의 전진 상황을 기록한다. 구분자는 `-`이다.
  - [ ] 모든 라운드가 종료되면 가장 많이 전진한 자동차를 구한다. 동률이라면 모두 구한다.
- [ ] 모든 결과를 출력한다.

## 예외 상황
- 모든 예외 케이스는 'IllegalArgumentException'을 던진다.

## 모델

### Car

#### field
- `name`(`String`) : 자동차 이름, 최대 5자의 길이를 가질 수 있다.
- `mileage`(`int`) : 자동차의 라운드별 누적된 전진 상황

#### method
- `advance()` : 자동차를 전진시킬지 결정한다. 세부적인 전진 조건은 외부에서 정한다. 

### Track

#### field
- `cars`(`List<Cars>`) : 경주에 참가하는 자동차 목록
- `roundCount`(`int`) : 경주의 라운드 수
- `winners`(`List<String>`) : 경주의 우승자

#### method
- `raceStart()` : 자동차 경주를 시작한다.
- `endRace()` : 자동차 경주를 종료하며 우승자를 기록한다.
- `getRecord()` : 자동차 경주의 모든 기록을 반환한다.
